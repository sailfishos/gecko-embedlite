# Gecko EmbedLite

Sailfish OS integration of Mozilla Gecko ESR, providing the embedded browser
runtime used by [QtMozEmbed](https://github.com/sailfishos/qtmozembed).

This repository contains the EmbedLite embedding layer and components, Qt and
camera integration, and RPM packaging. Upstream Gecko is pinned in the
`gecko-dev` submodule; Sailfish-specific patches are maintained under `rpm/`.
